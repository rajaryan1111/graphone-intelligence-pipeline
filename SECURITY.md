# Security Policy

## Scope

This repository contains an AI/data pipeline prototype. Do not submit private source-system exports, credentials, access tokens, customer data, or production datasets to the public repository.

## Reporting a vulnerability

Report security vulnerabilities privately through the maintainer's GitHub profile. Include the affected component, reproduction steps, and potential impact.

## Secrets and data

Use environment variables for API keys and service credentials. Keep private source data outside Git. Pipeline outputs should preserve provenance without exposing confidential source content.
